# 検証記録 / 2026-10-25

## 実施済み

- npm run build: 成功（外部依存なし）。
- JavaScript構文チェック: 成功。
- Node自動テスト7件: 成功。
  - カット境界 / 最後のフレーム選択
  - 枚数・秒数・合計時間の検証
  - 未対応エンコーダーの拒否
  - 録画終了時のリソース解放
  - 不正な出力を成功扱いしない
  - 中止と後片付け
  - バックグラウンド移行時の中止
- 録画ライフサイクルのテストはモック。実エンコーダー・MP4互換性の検証ではない。
- Python + ネイティブFFmpeg代替版: 自作3画像＋20秒MP3から15秒の実MP4を生成。
- 代替版のffprobe: H.264 / AAC、1280×720、30fps、両ストリーム開始0秒・長さ15秒。
- 代替版のフレーム抽出: 5秒・10秒で画像が切り替わることを確認。
- 詳細: fallback-verification.json。

## 公開後の受入テスト

1. JPEG2枚＋PNG1枚と30秒超のMP3で、各5秒の15秒MP4を作成。
2. 前後移動で順序を変えて、プレビューと出力が一致すること。
3. 端末に保存し、標準動画プレーヤーで音声・長さ・シークを確認。
4. 各10秒の30秒出力、1080pも試す。失敗したら720pへ。
5. 5秒以下の短い音声で、残りが無音になること。
6. 生成を中止 → すぐ再生成。アプリ切替 → 中止表示 → 再生成。
7. 不正な秒数、4枚選択、非対応画像、壊れたMP3のエラーを確認。
8. 拍や短い効果音と画像切替を合わせ、同期を視聴確認。必要なら出力をffprobeで検証。

現時点でユーザー指定の完了条件は未達成。実装ファイルとネイティブ代替版の成功を、Androidブラウザー版の成功として扱わない。
